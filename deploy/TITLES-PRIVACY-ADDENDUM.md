# Prepared visual title privacy paragraph

For review before activating visual title suggestions. This file does not update
the published notice.

If you enable AI autofill in Creator Studio, Ziipa automatically
sends one resized image or video frame to Cloudflare Workers AI to suggest a
descriptive title and a brief description. The preview is limited to 512 pixels on each side and 144 KiB,
and is re-encoded as JPEG without the original file metadata. That request does
not send your filename, audio, account history or the rest of your media library
to the AI provider. Ziipa does not store the preview or proposal as account
content through this feature. Suggestions appear as editable values in empty
title and description fields. Text you have already entered is preserved. Review
or edit the values before saving; saving or publishing remains a separate action.
The switch applies to the current editor session and can be turned off at any time.
Cloudflare processes the preview under its applicable AI data-use information
and privacy terms. Suggestions can be inaccurate, so you may edit the title or
enter your own. Declining preview sharing does not prevent manual creation,
draft saving or publication.
