# Ziipa Facebook brand assets

Upload-ready files:

- `ziipa-facebook-cover.png` — 1640 × 624 Facebook cover image.
- `ziipa-facebook-profile.png` — 1080 × 1080 square profile image with circular-crop protection.

Editable files:

- `ziipa-facebook-cover-editable.svg`
- `ziipa-facebook-profile-editable.svg`

Both SVG files can be edited in Figma, Illustrator, Inkscape, or a text editor. The artwork is grouped into named layers, and the headline remains editable text. Linked image layers are stored in `source-assets/`; keep that folder next to the SVG files when editing.

The cover keeps its important content inside the center safe area to reduce Facebook desktop/mobile cropping. Check the final crop in Facebook before publishing because Page layouts can vary by device.
